# `02.inputs/derived/`: the only committed data in the project

These three CSVs are the output of stage 1 and the input to stage 2. They are small,
text, and **committed to git**, because they are the numbers the manuscript cites and the
project rule is that no figure may be quoted from code that was not saved. Everything they
were computed from is raw third-party data that stays out of the repository.

Each file is regenerated by running its script from inside `05.scripts/`. Nothing here
should ever be edited by hand: if a number is wrong, fix the script and re-run.

| File | Rows | Script | Read by |
|---|---|---|---|
| `irish-soils-area-by-class.csv` | 75 | `prep-irish-soils.R` | Results, "The national soils map has no carbon stock for peat" |
| `irish-crt-peat-balance.csv` | 140 | `prep-irish-crt.py` | Results, "Ireland's own inventory, added up" |
| `irish-saltmarsh-salinity.csv` | 15 | `prep-irish-saltmarsh-salinity.R` | Results, "How much Irish saltmarsh is exposed to the salinity gate" |

## `irish-soils-area-by-class.csv`

One row per distinct combination of soil association, drainage, texture, depth and SOC
value, retaining **all 25,143 polygons** of the Irish Soil Information System map.

| Column | Meaning |
|---|---|
| `assoc_symbol`, `assoc_name` | Soil association identifiers |
| `drainage`, `texture`, `depth` | SIS classes; `(none)` where the source is null |
| `soc_present` | `TRUE`/`FALSE`. **The load-bearing column**: SOC is null on 32.3% of the mapped area and on 92% of the peat |
| `soc` | Soil organic carbon, t C/ha, association-level, `NA` where absent |
| `area_ha_geom` | Area computed from the polygon geometry |
| `area_ha_stated` | The map's own `Ha` column, for cross-check. The two agree to 0.04% nationally |
| `n_polygons` | Polygons collapsed into the row |

Nulls are encoded as the string `(none)` rather than left as `NA` before grouping,
deliberately: an `aggregate()` over raw `NA`s silently dropped 14,341 of 25,143 polygons and
a third of the national area in an earlier version. The script asserts that polygon counts
reconcile.

## `irish-crt-peat-balance.csv`

One row per category per year, **1990 to 2024**, from Ireland's Common Reporting Tables.

| Column | Meaning |
|---|---|
| `year`, `category` | `industrial_drained`, `industrial_rewet`, `domestic_drained`, `near_natural` |
| `area_kha_4D`, `area_kha_4II` | Area as reported in each table. **These differ**: 62.68 against 34.66 kha for drained industrial extraction in 2024, a completeness gap of 28.02 kha carrying CO2 but no CH4 or N2O |
| `soilC_tC_ha` | On-site soil carbon stock change, Table 4.D, **CRT sign convention: positive = gain** |
| `co2_kg_ha`, `n2o_n_kg_ha`, `ch4_kg_ha` | Off-site CO2, N2O-N and CH4 per hectare, Table 4(II) |
| `total_AR5_GWP100` | Full balance at Ireland's own reporting metric (CH4 = 28, N2O = 265). **Positive = net source** |
| `total_AR6_GWP100`, `total_AR6_GWP20` | Same balance at AR6 Table 7.15 values |

The totals are the sum of the on-site and off-site terms, with the Table 4.D sign flipped so
that positive means emission throughout. Notation keys in the source (`NO`, `NA`, `IE`, `NE`)
are read as missing, **never as zero**.

## `irish-saltmarsh-salinity.csv`

One row per habitat stratum and salinity class.

| Column | Meaning |
|---|---|
| `stratum` | `Annex I saltmarsh, confirmed` / `, potential` / `Spartina sward` / `Mudflat/sandflat (not saltmarsh)` / `Other, non-Annex` |
| `salinity_class` | `Below 18 ppt throughout` / `Spans 18 ppt` / `Above 18 ppt throughout` / `Not surveyed` / `Outside any transitional water body` |
| `area_ha`, `n_polygons` | Totals |

Only the **confirmed** Annex I stratum is quoted in the manuscript. Potential polygons are
desk-mapped rather than visited and are kept separate; mudflat is excluded from every
saltmarsh total. Read the limitations in `../IRL/README.md` before using any figure from
this file: the salinities are water-column, single-survey, and cover 9 of 195 water bodies.
